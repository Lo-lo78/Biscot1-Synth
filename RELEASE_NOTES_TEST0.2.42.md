# Biscot1 Synth VST3 TEST0.2.42 — Tracker keyboard navigation

- F1 Pattern and F2 Song grids: Ctrl+Up/Down now move among header, remembered steps and footer/repeat areas.
- F1: Ctrl+Shift+Up/Down selects previous/next Pattern (0–999), retaining cursor area and position.
- F2: Ctrl+Shift+Up/Down selects previous/next Song (0–99), retaining cursor area and position.
- Ctrl+Home/End no longer moves among regions in the F1/F2 grids; unmodified Home/End still navigates inside the current region.
- The F1/F2 parameter pickers retain their own keyboard behavior. All other controls are unchanged.
- Full Windows VST3 compilation and NVDA/OSARA testing remain to be performed.
